# Library Management System (LBMS)

## Overview
A comprehensive system for managing library operations, including book catalog management, member management, and transaction processing.

## Features
- Book catalog with search functionality
- Member management
- Borrow/return/renew flow
- Overdue fine calculation
- Admin dashboard
- Role-based authentication (admin/librarian/member)

## Tech Stack
- **Frontend**: Next.js, TypeScript, Tailwind CSS
- **Backend**: Node.js
- **Database**: PostgreSQL with Prisma

## Getting Started

### Prerequisites
- Node.js
- PostgreSQL

### Installation
1. Clone the repository
2. Install dependencies
   ```bash
   npm install
   ```
3. Set up the database
   ```bash
   # Prisma database setup commands
   ```
4. Start the development server
   ```bash
   npm run dev
   ```
